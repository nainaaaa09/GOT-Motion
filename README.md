# Winterfell Motion

A cinematic Game of Thrones inspired React + Framer Motion experience with immersive scroll animations, character sections, cinematic transitions, audio ambience, and interactive visuals.

## Live Demo

https://winterfell-got.vercel.app/

## Tech Stack

- React
- Vite
- Framer Motion
- CSS3

## Features

- Cinematic scroll animations
- Game of Thrones theme music
- Interactive character panels
- Video transitions
- Responsive layout
- Motion-based storytelling
